# 使用网页

## 打开与切换

1. 打开在线地址或双击完整项目中的 `docs/index.html`。
2. 在“选择模型”里选字符 1—2 gram、jieba 或字符 1—4 gram。
3. 等待“模型已就绪”，输入 1—500 字，点击分析。切换模型会清掉旧结果，但保留输入，需再次点击分析。

首次按需加载约 11—12 MB 参数，jieba 另需约 5 MB 词典。HTTP 模式用 Worker 避免推理阻塞界面，直接打开文件时使用 JavaScript 参数包。失败时点击重新加载；页面发布后若版本不一致可强制刷新。移动端和深浅主题均可使用。

jieba 结果下方显示切分出的词。三个模型仍只输出正、负两类。±0.5 的提示与表情是界面辅助，未对新增模型重新校准，不代表中性标签或统计显著性。分数不能跨模型直接比较。

## 本地启动

`start_demo.bat` 会检查 Python 3.12 和依赖，首次可能联网安装。它打开与 Pages 相同的网页。开发者也可用虚拟环境运行 `python app.py --open`。本地 `/predict` 接口支持 JSON：`{"text":"今天很开心","model":"jieba"}`，model 可取 char2、jieba、char4，省略时用 char2。

## 演示建议

课前预先切换三次，确保模型加载完成。准备普通评价、否定、转折各一条，也允许现场输入。不要把挑选的几句示例当作准确率证明。PPT 的二维码与按钮访问在线版本，若尚未发布新版本应使用本地网页并说明。
