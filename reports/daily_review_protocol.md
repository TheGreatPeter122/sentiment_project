# 日常评论、多来源与结构特征优化：预先固定的方案

日期：2026-10-11。用户已确认：优化日常评论整体表现、否定与转折句；暂缓人工情感标注，社群黑话不在后续实验范围。

## 数据处理与划分

恢复已有固定版本的购物、外卖 CSV，验证来源 SHA256；复用 clean_external_data.py，核对清洗结果的历史哈希。该脚本为防止交叉污染读取原微博三份划分的正文指纹，但不进行原测试集模型评价。

外部同源指纹已合并去重；同时来自购物/外卖的 20 条文本单独隔离，避免给它们随意指定来源或重复计入来源指标。剩余记录按来源、标签分层，以 `daily-review-20261011-v1` 加 ID 的 SHA256 排序，分别取前 floor(80%) 为训练、中间 floor(10%) 为验证、剩余为保留测试。保留来源、类别、ID、指纹及清洗规则。微博沿用原训练/验证划分；原测试集不评价。

外部保留测试集在方案和代表模型确定前不参与词表、权重、规则与模型选择；最后仅评价锁定的新模型和锁定的同轮微博单来源对照。测试后不再据结果调参。

## 阶段 A：数据组成对照

1. `weibo_only`：只用原微博训练集。
2. `mixed`：微博＋外部训练集直接混合，每条样本权重 1。
3. `balanced`：相同混合记录，来源×标签每格贡献相同的总权重，权重整体均值为 1；不复制或删除记录。

三组均去表情、字符 1—2 元 TF-IDF（min_df=3，max_features=120000）。统一 SGD 逻辑回归：loss=log_loss，alpha=1e-5，max_iter=50，tol=1e-3。固定三种种子 20261010、20261011、20261012，报告均值和样本标准差；不将三次随机种子当作独立数据集。

选择依据是各种子上微博/购物/外卖三来源验证 Macro-F1 的等权平均，避免大来源掩盖小来源。平分优先列表中较简单方案，容差 1e-8。各组在完全相同的验证记录上评价，记录每来源准确率、F1、混淆矩阵、计算耗时及来源权重。

## 阶段 B：结构特征对照

在阶段 A 选定的数据组成上比较字符基线、v1 否定＋转折特征、v2 改进规则特征。v1 使用前轮规则；v2 在提取候选时排除以下词内命中：`特别、分别、区别、告别、别人、别的、别处、别样、别致、别墅、别名、未来、无论、无数` 中的否定字符，以及 `但愿、不但、忙不过来` 中的转折字符。保留偏移量和原文，局部上下文不因词内排除被截断。规则来自前轮观察及明确的词语用法，未看新保留测试结果。

改进不硬编码情感标签，也不声称解决词法/句法的全部歧义。“无语”“不得不”“不过”及多重转折仍可能含不同语用含义。

三来源及否定/转折子集同时评价；所有方案使用同一份 v2 候选掩码构造评价子集，避免各自筛选造成分母变化。规则变化前后的候选数量另行记录。阶段 B 沿用三个固定种子；按三来源验证 Macro-F1 均值选择，平分优先基线，再 v1，再 v2。

不基于已知诊断句选模型。仅保留普通、否定、转折、反讽、混合及中性开发用例；不加入或讨论社群黑话用例。

## 交付与解释

记录清洗/划分/候选提取/权重计算/向量化/训练/评价的阶段数量、时间、输入输出哈希、来源及标签分布、特征维度和逐条预测。原文、处理轨迹、新模型保存在 Git 忽略目录，汇总报告及代码可供版本管理。

固定 seed=20261010 为代表模型，不挑选测试成绩最高的随机种子。新增保留测试主要证明购物/外卖场景的探索性结果，不证明微博或真实线上分布的普遍提升。指标依赖来源标签，人工审定仍未进行。

本轮是单机实验。允许报告混合规模增加带来的效果变化，不把混合方案优势完全归因于数据多样性；训练条数变化也是影响因素。网页模型是否替换另行依据结果决定；默认先保存独立可运行的新模型。
