# 否定与转折特征实验：训练前固定的方案

日期：2026-10-11。目的：记录文本处理步骤及其对既有情感分类器的影响，作为《大数据导论》数据处理过程的案例。

## 输入与控制条件

- 使用已有微博语料固定版本，原始 SHA256 为 `2d0a49e27de5295a84893e07816e131c0d116ecbbcbb624418d4e10bebf97a1b`。
- 本机缺少原训练数据，先恢复上述版本，复用 audit_data.py 和 prepare_splits.py；重新生成的三份划分须与已有 split_report.json 的哈希一致。
- 训练 88,814 条，验证 10,908 条。原测试集只核对文件哈希，不读取内容、不预测、不用于选方案。已有历史测试成绩不视为本轮独立评价。
- 保留原有 0=负向、1=正向标签，不增加人工标签，不混入攻击性或 NLI 标签。所有组使用相同记录、顺序和标签。
- 本轮选择字符 1—2 元基线，便于单独观察规则特征作用；已有分词组合实验另列为历史结果。

## 三组方案

| 组 | 特征 |
| --- | --- |
| baseline | 去表情字符 1—2 元 TF-IDF，min_df=3，max_features=120000 |
| negation | 基线 + 否定标记计数、同小句多次否定候选、标记及其后最多 4 字的前缀组合 |
| negation_contrast | 前组 + 最后一个转折标记前/后的独立字符 TF-IDF，各最多 40000 维 |

所有 TF-IDF 及否定字典仅在训练集拟合。否定字典丢弃训练文档频次少于 3 的键；各特征块单独 L2 归一化，以固定权重 1 拼接，不根据结果调权重。

分类器统一使用 SGDClassifier(loss=log_loss, alpha=1e-5, max_iter=50, tol=1e-3, random_state=20261010)。属于从固定数据重新拟合三组对照模型，并非对现有模型增量训练。

## 规则的解释边界

- 先移除 1—15 字的方括号表情，与原基线相同；保留正文、标点和词序。不删除否定词作为停用词。
- `不但、不仅、不光、不只、不止` 不当作否定或转折触发词，其余规则候选见 structure_features.py。
- 否定局部组合遇空白、标点或转折词停止；最多取后续 4 字，不声称获得真实句法作用范围。
- 同一小句出现至少两个否定标记只算“多次否定候选”，不直接翻转情感标签。
- 最后一个转折标记用于构造位置通道，不给后半句硬编码更高权重。词内误命中、多重转折、引用、反讽仍可能处理错误。

## 评价与记录

在同一验证集比较准确率、Macro-F1、混淆矩阵，以及否定候选、转折候选、两者同时出现、多次否定候选、均无候选等子集。子集可以重叠，不能相加。

对每个增强组记录相对基线的“改对、改错、仍错”数量，原文与逐条预测只保存在 Git 忽略的本地处理目录；它们是按原标签自动归类的错误，不等于人工语义审定。

已有诊断句和用户提供的两句仅用于开发观察，不加入训练，不用于选方案，也不作为独立测试成绩。按全体验证集 Macro-F1 选择探索性最佳组，平分优先简单方案。本轮不根据诊断结果反复调参。

记录输入/代码/模型哈希、环境版本、各步骤行数、候选频次、特征维度、矩阵非零数、处理和拟合耗时、训练警告、逐条处理轨迹与模型重载校验。模型单独保存，不自动替换演示模型。
